## 1. 项目身份

| 项 | 值 |
|---|---|
| 参赛项目名 | **安棚** —— 农村草料棚智能火灾预警与初期喷淋系统 |
| 公司主体 | **安棚智慧消防科技有限责任公司** |
| 英文标识 | **ANPENG** |
| 一句话 | 给中小养殖户的草料棚装一套买得起、装得上、不用改建筑的自动火灾预警与初期喷淋装置 |

## 4. 业务域模型（两端**必须**一致）

### 4.1 硬件链路（演示与说明口径必须与此一致）

```
MQ-2 烟雾/可燃气体  ┐
                    ├─→ STC89C52 单片机 ─→ 蜂鸣器（三级鸣响节奏）
PT100 铂热电阻      ┘        │
（经 MAX31865 采集）          ├─→ 5V 继电器 ─→ DC12V 常闭式电磁阀 ─→ 开式喷头
                            │
                            └─→ ESP-01 WiFi ─→ OneNet 云平台 ─→ 应用（本软件）
```

- **常闭式**电磁阀：断电即关，更安全。**确认火警才开阀**。
- **成本口径**：小型单点装置综合造价 **≤1000 元**。
- **适用前提**：现场水压、流量与喷头覆盖满足要求；安装前核查扬尘干扰、喷淋覆盖与电气隔离。
- **保护对象**：核心是**草料区**，**牛羊圈舍**为邻近保护对象；喷淋方向**避开配电箱、插座和牲畜活动区**；涉及带电设施的火情需先安全断电后处置。

### 4.2 三级分级判断（**必须逐条实现并在 UI 上可视化**）

| 级别 | 触发条件 | 动作 |
|---|---|---|
| **环境预警** | 单项异常（仅烟雾或仅温度超限） | 蜂鸣器短促单响；界面黄色提示「建议检查」；**不喷淋** |
| **疑似火情** | 烟雾与温度**同时**异常 | 蜂鸣器连续双响；界面橙色报警；推送棚主；**不喷淋** |
| **确认火警** | 两项**连续超限** ＋ 满足**温升速率**或**持续时长** | 蜂鸣器长鸣；**开阀喷淋**；远程推送；写入处置记录 |

**防误喷/漏报设计**：连续采样滤波 + 温升趋势；前两级不喷淋；针对**草料扬尘**做干扰试验。

#### 4.2.1 判定取数口径与时间戳护栏（2026-10-14 增补，两端必须字面同名同值）

1. **判定必须使用原始采样值**（烟雾 `ppm` 原值、温度 `°C` 原值、温升原值），**不得先把展示取整值赋给局部变量再参与阈值比较**。展示端允许取整，但必须选**最小**小数位，使「显示值与阈值的关系」与「原始值与阈值的关系」同真假 —— 即界面上写的 `≥` / `<` 必须字面为真。（起因：两端都曾用 `r0/r1/r2` 取整值判定，导致 `799.6 ppm` 被判超限、`69.96 °C` 被假称命中 70 ℃ 阈值、真实 `3.95 s` 被取整成 `4.0 s` 而开阀。）
2. **时间戳护栏 `maxSampleGapMs = 15000`**（配套 `maxSampleGapSeconds = 15`）：相邻两次采样的时间差**超过**该值时，视为数据不连续 → 清空温升窗口、**三个连续计时器全部归零**、标记 `timeAnomaly = true`。该常量是**墙上时间口径，刻意不从 `samplePeriod` 派生**；取值理由：下界须容纳真实上报抖动（实测最坏「57 s 只 13 个样本 ≈ 4.75 s 间隔」的三倍余量），上界必须严格小于「连续超限确认时长 30 s」且只取一半，使**单次跳变无法独自凑出「连续 30 s」**。时间戳**倒退**或**相等**同样清零三个计时器，绝不产生负时长或 NaN。
3. 该护栏不得变成"永久哑火"：跳变后重新真实累计，仍应正常升级（回归用例：+1 h 跳变后被污染的 `3658 s` 必须回到真实 `58 s`）。
4. 两端 `--parity` 输出的 `thresholds` 必须包含 `maxSampleGapMs` / `maxSampleGapSeconds`，以便跨端逐字段 diff。

### 4.3 数据点

| 字段 | 单位 | 说明 |
|---|---|---|
| 烟雾浓度 | `ppm` 等效 / ADC 原始值 | MQ-2 |
| 温度 | `°C`（一位小数） | PT100 + MAX31865，三线制 |
| 温升速率 | `°C/min` | 滑动窗口 |
| 超限持续时长 | `s` | 连续超限计时 |
| 电压/在线状态 | `V` / 在线\|离线 | ESP-01 / 节点心跳 |
| 阀门状态 | 关\|开\|故障 | 继电器回读 |
| 喷头状态 | 正常\|堵\|未知 | 巡检录入 |

### 4.4 默认阈值（可改，必须可改）

| 项 | 默认值 |
|---|---|
| 烟雾预警阈值 | `800` ppm |
| 温度预警阈值 | `55.0` °C |
| 温度确认火警阈值 | `70.0` °C |
| 温升速率阈值 | `5.0` °C/min |
| 连续超限确认时长 | `30` s |
| 采样周期 | `2` s |

## 5. Windows 桌面监控台（`anpeng/desktop`）

- 工程名 `Anpeng.Desktop`，`RootNamespace=Anpeng.Desktop`，输出 `安棚.exe`（`AssemblyName` 用 ASCII，`ApplicationIcon` 用自制 `Assets/AppIcon.ico`）。
- 外壳：`Window` + WinUI 3 **`TitleBar`** 控件（左侧图标=安棚方版标志）+ **`NavigationView`** + `Frame`。
- 导航 **8 项**（**页面与导航项名称必须完全一致**）。第 8 项是**诊断页**，非产品功能页：它让评委在应用内自证「三级分级判断」真的按契约运行（第 7 节验收线 3 要求的「可被证伪地演示」），故保留并单列，不计入产品页数。2026-10-14 修订：原为 7 页，实现新增自检页后按检查手 B 的 D-6 同步契约（改契约而非砍功能，理由是自检能力本身是参赛证据）。

| # | 导航项 | 关键内容 |
|---|---|---|
| 1 | **总览** | 棚舍卡片墙（≥4 个棚）；每棚：名称、状态灯（四级色）、当前烟雾/温度、阀门状态、最近报警时间；顶部汇总带（在线节点 / 今日报警 / 喷淋次数 / 平均温度） |
| 2 | **实时监测** | 选中棚的实时双曲线（温度 + 烟雾），带阈值参考带；当前读数大字 + 温升速率 + 超限计时；采样表（最近 30 条） |
| 3 | **报警记录** | 三级分级列表（筛选：全部/环境预警/疑似火情/确认火警）；每条含时间、棚、触发值、级别、**处置动作**（是否喷淋）、处置人、备注；详情面板展示"触发 → 判断 → 动作"链路 |
| 4 | **喷淋控制** | 阀门当前状态大卡；**手动开阀**（必须二次确认对话框，危险色）+ 手动关阀；喷淋历史（时长、原因、触发级别）；管路自检按钮 |
| 5 | **设备管理** | 棚舍增删改；节点列表（MQ-2 / PT100 / 电磁阀 / ESP-01），在线状态、固件版本、信号强度；传感器校准记录；喷头巡检记录 |
| 6 | **报表统计** | 日报 / 周报 / 月报切换；报警次数按级别堆叠柱状、按棚分布；喷淋次数趋势；导出按钮（CSV） |
| 7 | **设置** | 阈值设置（第 4.4 节全部项）；报警声音开关；判据联动说明；数据与账号；**关于**页展示安棚标志（横版或竖版）+ 版本 + 公司全称 |
| 8 | **判据自检**（诊断页，非产品功能） | 在应用内对判定引擎跑一遍固定用例并显示「输入 → 级别 → 是否喷淋 → 命中分支」，供评委当场证伪第 4.2 节三级分级判断。标题栏/导航项必须含「自检」二字以免被误认为产品功能页 |

- **设置页反向要求（2026-10-14 增）**：设置页上**每一个开关都必须有真实读取点（read site）**。只写不读的开关等同于对用户说谎 —— 与第 4.2 节「界面文案必须与引擎真实行为一致」同源。若某项功能本应用无法实现（例如需要联网的远程推送），**允许保留开关，但文案必须写明它是实机部署链路的预留项、当前不生效**，不得写成正在生效的承诺。

- **判定引擎必须是一个可单测的纯逻辑类**（如 `AlarmEvaluator`），输入一次采样 + 当前状态，输出级别与动作；三级升级、连续超限计时、温升速率都要有真实实现。
- 演示数据：≥4 个草料棚、≥30 条报警记录（三级齐全）、≥20 条喷淋记录、≥200 个采样点。全部中文、草料棚语境。
- 数据可持久化到 `%LOCALAPPDATA%\安棚\`（JSON），但**首次启动必须自带完整演示数据**。

## 7. 验收线（8 条，两端都要过）

1. **控制台零 error**：桌面端运行期无未捕获异常；移动端 logcat 无 `FATAL EXCEPTION`。
2. **安棚标志真实出现**：桌面端在标题栏 + 关于页；移动端在启动图标 + 关于页。像素/几何级验证，不接受"放了张图"。
3. **三级分级判断可被证伪地演示**：能构造出"单项异常→不喷淋 / 烟温同时→仍不喷淋 / 连续超限+温升→开阀"三条链路，且界面上看得到区别。
4. **两类产物存在且可运行**：`dist/安棚 1.0.0.exe`（双击起窗口）+ `dist/安棚-v1.0.0.apk`（`aapt dump badging` + `apksigner verify` 通过）。
5. **离线可用**：断网状态下全部本地功能正常，界面明示"本地运行中"。
